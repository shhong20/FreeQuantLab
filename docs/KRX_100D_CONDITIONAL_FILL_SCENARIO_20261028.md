# KRX 100일 거래중단 인식형 조건부 체결 시나리오 (2026-10-28)

## 목적·안전 계약

`quantlab.intraday_krx_halt_scenario`는 **실제 증권사 체결을 검증한 백테스트가 아니다.** SHA-256으로 검증된 KIS 1분봉에서 만든 위험 분리형 5분봉을 사용하지만, KIS의 `stck_cntg_hour`는 공개 예제에서 '주식 체결 시간'으로 소개될 뿐, 5분봉의 시작 시간이라는 공식 계약과 특정 가격의 체결 가능성을 확인하지 못했다. 따라서 결과 이름은 `CONDITIONAL_KRX_OPEN_FILL_SCENARIO_NOT_VALIDATED_BACKTEST`로 고정한다.

데이터: 2026-05-28~10-23 KRX 실제 원본, 삼성전자(005930)·SK하이닉스(000660) 각 100거래일, 종목·거래일 스냅샷 총 200개, 5분 시간 슬롯 15,200개. 리서치 원본은 불변.

입력:
- `krx100_halt_5m_20261028_r2`: 매 시간 5분 슬롯, 원본 SHA, 위험·누락·경매 라벨 분리. 전체 200개 종목·거래일 보존.
- `krx100_halt_position_stress_20261028_r1`: 종목별 8번의 2026 코스피 거래중단 위험 상황, 총 16개 스트레스. 이미 보유한 10주는 임의 청산하지 않으며, 중단 중 미체결과 재개 후 자동 주문도 없다.

### 거래 모델 (연구 시나리오 전용)
- KIS의 분봉 시간이 **구간 시작 라벨**이고 주문 의도 시점 이후 다음 봉 **시가로 전량 체결**한다는 가정 하에만 가격 계산. 실제 호가·체결가·체결량·대기열은 알려져 있지 않다.
- **전체 거래중단, 원인불명 데이터 누락, 종가 라벨 불확실 일**은 당일 신규 진입 금지. 100일의 분모에는 그날도 유지. 이 전략 시나리오는 매일 장 마감 전 **현금 포지션으로 돌아온다는 가정**이므로 CB 위험일에는 아예 신규 주식 노출을 만들지 않는다.
- 기존 보유 주식이 거래중단에 걸렸을 때의 손실이나 체결가를 만들어내지 않고, 별도 스트레스 원장으로 확인. **보유 중 위험의 실현손익까지 설명하는 모델은 아님**.
- ORB 5·15·30분과 첫 30분 모멘텀. 당일 첫 구간 거래량은 직전 **완전 관측** 20거래일 중 최근값의 중앙값과 비교, 최소 10개 과거 사례 필요. 당일 값이 자신의 과거 비교 기준에 누설되지 않음.
- 5분봉 `N`의 완료 후 **N+1 시가 진입**, 마지막 정규장 15:15 봉 **시가 청산**을 가정. 15:20~15:30 단일가매매 시가 체결은 가정하지 않는다.
- 주문 수량은 가상 1,000만 원 기준, **신호를 만든 과거 완료 5분봉의 거래량 1% 이하**로 제한한다. 미지의 미래 매수/매도봉 거래량으로 과거 주문량을 결정하지 않는다. 이 1%는 주문 체결 가능량 인증이 아님.
- 기본 가정 비용: 매수/매도 각각 3bp 수수료 + 5bp 슬리피지, 매도 20bp 세금. 수수료/슬리피지만 2배로 늘린 스트레스 결과 병행. 국회예산정책처 2026 조세 보고서의 코스피 거래세 0.05%+농특세 0.15%를 참조하며, 실제 계좌 수수료는 개별 확인이 필요. 출처: https://www.nabo.go.kr/board/file/down.do?fid=33319156
- 한국주식 갭 반등은 공식 종가 단일가·기업행동 원장 미검증으로 제외. 단기 전략만의 조건부 수익으로 제한.
- 100거래일 순서 고정: 앞 60일 준비, 다음 20일 검증, 마지막 20일 **사전에 구분한 테스트 구간**. 기존 신호 감사에서 테스트 구간의 신호 빈도는 이미 공개되었으므로, 완전 무노출 블라인드 테스트는 아니다. ORB 계열 선택은 검증기간 최소 3건 이상의 가상 체결 사례를 요구한다. 테스트 10건 미만은 `DIAGNOSTIC_ONLY_INSUFFICIENT_TEST_TRADES`. 각 종목·전략군을 분리하고 검증기간에만 전략 변종 선택. 빈 날의 0 수익은 **현금 보유**이지 OHLCV 보간이 아니다.
- 거래중단 위험/결측일은 전략 수익률을 불리하게 만들 수도 있으므로, 이 조건부 시나리오의 **거래중단 당일 무진입 정책** 자체가 성과를 과대평가할 가능성도 있다. 과거 CB를 미리 알고 오늘 하루를 회피한 전략의 실현 가능 성과가 아니다! CB가 예측 불가능하게 발생하는 날의 사전 진입 가능성을 생략한 보수적인 **사후 위험 제외 정책**의 결과이며 **실거래 가능한 기대 수익률이 아니다**.
- **포지션 진입 시점에 CB 발생 여부를 미래에서 알 수 있는 '하루 전체 차단'은 룩어헤드**다. 이 때문에 사용자는 어떤 수익률도 실제 전략 능력의 미사용 테스트 결과로 취급해서는 안 된다. 완전한 일중 리플레이에 상태 전이·체결 원장이 갖춰지기 전까지 수익률 검증을 승인하지 않는다.

**위 숫자는 실현손익/검증된 백테스트가 아니다.** 데이터 원본이 많아졌다는 것만으로 돈 버는 전략의 증거로 사용해서는 안 된다.
