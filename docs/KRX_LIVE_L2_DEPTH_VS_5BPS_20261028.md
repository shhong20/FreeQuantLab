# FreeQuantLab KRX 실시간 L2 호가와 5분봉 체결 가정 비교 (2026-10-28)

## 요약
기존 100거래일 KIS KRX 1분/5분봉 연구는 **미래의 5분봉 시가로 전량 체결하고 매수/매도 각 5bp를 슬리피지로 적용하는 조건부 가정**을 포함한다. 체결 호가·대기열·주문 지연·실제 주문 원장이 없으므로 과거 수익률이 확정되지 않는다.

이번 작업은 KIS의 공식 KRX 기본시세 호가 조회(`/uapi/domestic-stock/v1/quotations/inquire-asking-price-exp-ccn`, `TR_ID=FHKST01010200`, KRX J, 삼성전자 `005930`, SK하이닉스 `000660`)를 직접 **읽기 전용 GET**으로 호출했다. 인증키는 HTTPS 요청 헤더에만 사용하고 파일에는 저장하지 않았다. 브로커 주문·체결·취소/잔고 API 호출 0건.

공식 레퍼런스: https://github.com/koreainvestment/open-trading-api/blob/main/legacy/Sample01/kis_domstk.py

- 2차 수집은 각 시장 데이터 원본 응답과 정규화된 10호가 매수/매도·잔량 응답을 **각각 SHA-256으로 저장·재대조**. 1차는 정규화 영수증과 응답 해시만 저장해 원본 복원 가능성은 제한적.

- 1,000만원 주문 금액 기준 실제 가격에서 가능한 최대 수량은 2차 마지막 호가 기준 삼성전자 약 41주, SK하이닉스 약 6주. 500~1,000주 테스트는 체결 비용의 **대규모 주문 민감도**를 확인하는 별도 시나리오다.

## 1. 중간가격 기준 매수·매도 호가 비용

*단위 bp(1bp=0.01%); 10주 정도의 시장가 주문을 표시된 1호가 물량에서 전량 매칭한다고 상상할 때, midpoint에서 얼마만큼 불리한가. 이는 과거 5분봉 시가 대비 슬리피지 또는 실제 주문 체결값과 동등하지 않다.*

## 2. 실제 표시 잔량 소진 민감도

시장가 주문의 호가 화면에서 보이는 10호가만 대상으로 VWAP를 계산하며, 화면에 있는 잔량이 취소·변경·선체결되지 않는다는 가정이다. 주문이 실제로 체결될 가능성을 측정한 게 아니다.

| 시점·종목 | 10주 매수/매도 | 500주 매수/매도 | 1,000주 매수/매도 |
|---|---|---|---|
| 13:20 삼성전자 | 10.36/10.36bp | 10.36/10.36bp | 10.36/10.36bp |
| 13:20 SK하이닉스 | 3.38/3.38bp | 3.38/7.71bp | 3.38/8.93bp |
| 13:23 삼성전자 | 10.36/10.36bp | 10.36/10.36bp | 10.36/10.36bp |
| 13:23 SK하이닉스 | 3.39/3.39bp | 3.39/3.39bp (2/6은 5bp 초과) | 3.41/3.39bp (2/6은 5bp 초과) |

해석: 삼성전자는 당시 스프레드의 절반이 이미 5bp 가정보다 높았다. SK하이닉스는 작은 주문에는 낮았으나 500~1,000주 매도 일부/전부 시점에서 다른 매수호가까지 필요했다. **주문량·매매방향·시점별 마찰비용 모델**이 고정 5bp보다 적절하다.

## 3. 과거 전략 성과와의 대응 여부
- 이전 PIT 자료: `krx100_pit_replay_20261028_r3` (2026-05-28~10-23, 100일×2종목=200 종목·거래일).
- 이번 호가 날짜는 2026-10-28이므로 과거 PIT 신호와 **동일 시각/동일 날짜의 호가 데이터가 전혀 없다**. 원본 1분봉과의 체결 가격/호가 대기열 일대일 비교는 **0건**이다.
- 따라서 100일 누적수익률·MDD·샤프·수수료 보정 신규 수익률은 이번 실측으로 확정하지 않는다. 과거 전략의 기존 가상 청산 이벤트도 실제 체결 영수증으로 승격하지 않는다.
- 주식 호가와 암호화폐(Upbit) 미시구조 아카이브는 서로 다른 자산 시장이므로 근거 없이 교차 비교하지 않는다.
- 현재 표본에 과거 거래 비용 파라미터를 맞추는 것도 오버피팅이므로 금지한다.
