## 안전 계약
- `XKRX` 거래 달력을 확인하고 2026-10-29의 허용 시각에만 실수집. 다른 날짜나 장외 시각에는 네트워크 호출 전 종료.
- KIS 앱 인증키/시크리트는 접근권한 0600인 `~/.config/freequantlab/kis.env`에서 **두 변수명만 파싱**한다. 셸 `source`로 실행하지 않는다. 캐시된 OAuth 토큰도 출력하지 않는다.
- 각 수집 단계의 응답 원문/정규화 JSON은 SHA-256을 계산해 별도 읽기 전용 불변 자료로 저장. 개별 요청 시각을 기록하고 연속 GET이 원자적 동시 관측이라고 주장하지 않음.
- 원본 폴더는 성공적으로 모든 응답이 검증될 때만 최종 이름으로 이동. 이후 `joint_comparison.json` 감사 파일이 별도 SHA-256으로 저장됨.
- 재실행 시 이미 감사 완료된 구간은 `ALREADY_AUDITED`. 수집만 완료된 구간은 재조회 없이 감사만 시도. 미완성 원본은 자동 복구/덮어쓰기 금지.
- 미확인 분봉·체결 가능성을 백테스트 수익률로 보간하지 않는다. `broker_orders=0`, `usable_for_paper_or_live=false`.

## WSL cron 조건과 한계
기존 사용자 `hong`의 `cron` 서비스가 살아 있는지 확인한 후, 필요한 경우 사용자 crontab에 **2026-10-29 날짜 한정 3개 작업**을 등록한다. 등록 내역과 실행 결과는 별도로 확인한다.
