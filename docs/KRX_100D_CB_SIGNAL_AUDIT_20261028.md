## 전략 신호의 안전한 예비 비교
`quantlab.intraday_krx_signal_audit`에서 원본 SHA가 검증된 위험 분리 자료만 읽어 고정 규칙 ORB 5/15/30분과 장초 모멘텀 30분의 **신호 발생 일수**를 집계한다. 모든 거래일을 유지하고, CB·결측·라벨 이상 거래일에는 신호 진입을 차단한다. 장 마감 경매/기업행동 자료가 부족한 KRX 갭 반등은 계산하지 않는다. 과거 신호가 많다는 사실은 수익이나 체결 확률을 의미하지 않는다.

60/20/20 연대순 구간으로 단순 나누지만 **선택·수익률·테스트 성과는 계산하지 않는다**. 신호 집계가 공개됐다고 미사용 성과 검증을 수행했다고 주장하지 않는다.
