# FreeQuantLab KRX 100거래일 시간순 리플레이 — 미래 거래중단일 차단 제거 (2026-10-28)

## 왜 새 엔진이 필요한가
PR #103의 조건부 비용 시뮬레이터는 전체 거래일의 `day_disposition`을 먼저 확인해 그날 서킷브레이커가 발생할 예정이면 개장 당시부터 진입하지 않았다. 미래 발생 이벤트를 미리 알고 거래를 피한 셈이어서 이 수익률은 실제 구현 가능한 전략 검증에 사용할 수 없다.

`quantlab.intraday_krx_pit_replay`는 데이터를 읽기 전에 이미 모든 사건을 알고 있더라도, **주문 판단 루프에서 그날의 종합 판정(`day_disposition`)을 참조하지 않는다**. 오직 시각별 슬롯과 마지막 완료 봉/그때까지 발생한 사건만 가지고 새 신호와 가정 진입을 결정한다.

### 1분봉·5분봉과 주문 시각의 한계
한국투자증권(KIS) 공식 예제는 `stck_cntg_hour`를 '주식 체결 시간'으로 명시할 뿐, 과거 1분봉 시작/끝 라벨을 보증하지 않는다.
https://github.com/koreainvestment/open-trading-api/blob/main/examples_llm/domestic_stock/inquire_time_dailychartprice/chk_inquire_time_dailychartprice.py

따라서 **5분 시작 라벨과 다음 봉 시가로 전량 체결한 가정은 검증되지 않았다**. 특히 완료봉 직후 다음 봉 시가에 지연 없이 진입/청산하는 가정에는 실제 주문 지연·호가잔량·시장충격 검증이 없다. 모든 '체결'은 `HYPOTHETICAL`이며 실제 브로커 요청 0건이다.

KRX 서킷브레이커 1·2단계는 거래 중단 후 재개가 필요한 제도이며, 거래중단 중에는 시장가 주문이 즉시 체결된다고 가정할 수 없다.
https://easylaw.go.kr/CSP/CnpClsMain.laf?ccfNo=3&cciNo=1&cnpClsNo=1&csmSeq=1701&popMenu=ov

기사에서 얻은 CB 시작 시각은 정식 KRX 머신 이벤트 피드나 실시간 전달 시각이 아니라 사후 보고값이다. 20분 중단+10분 단일가 추정 구간을 **보수적 주문 불능**으로 취급하지만 정확한 분 단위 체결 가능성을 인증하지 않는다.

## 실제 WSL 입출력 계약
- 원본: `krx100_halt_5m_20261028_r2`, 총 100거래일 × 2종목=200개 종목·거래일, 15,200개 5분 슬롯.
- 보유 스트레스: `krx100_halt_position_stress_20261028_r1`, CB 8거래일 × 2종목=16건, 기존 보유·중단·무체결 정책을 SHA로 연결.
- 전략군(종목별 분리): ORB 5/15/30분, 첫 30분 모멘텀. 신호 이전 완전봉만 참조. ORB 상대거래량에는 과거 정상 관측만 쓰며, 현재 봉을 과거 기준에 넣지 않는다.
- 신호 바 `i` 완료 -> 다음 바 `i+1` 가정 시가 진입. 가상 주문 금액 1,000만원 이하, 직전 완료 봉 거래량 1% 이내. 마지막 정규 연속매매 `15:15` 봉 가정 시가로 청산. 15:30 단일가 시간은 연속체결로 가정하지 않음.
- **일중 미확인 분봉·거래중단 발생 이전에는 거래중단일을 사전 회피하지 않는다.** 이미 가정 진입한 포지션이 원본 공백/CB와 겹치면 `FROZEN_UNRECONCILED`로 유지한다. 거래중단 중 가상 매도·재주문·사후 보간 없음.
- 다음 거래일에도 외부 잔고·재개 후 체결 원장 없이 냉큼 현금으로 초기화하지 않는다. 미해결 보유 포지션이 있다면 이후 모든 신규 거래를 보류.
- CB와 같은 5분 구간에 예정됐던 가정 진입은 확정 미체결로 단정하기보다 `PENDING_ENTRY_OVERLAPS_CB_UNCERTAIN`으로 기록한다. 이는 안전한 미체결 판단이 아니라 체결 가능성 자체가 미확정임을 뜻한다.
- 검증 가능한 `HYPOTHETICAL_CLOSE_BEFORE_AUCTION` 진입·청산만 개별 기록. 미해결 종목·전략 계좌에서는 전 기간 확정 수익률, 샤프, MDD = `null`. 모든 수익률은 **실현 성과가 아님**. 새 모델의 본래 목적은 *거래불능과 보유위험을 숨기지 않기*.

## 100거래일 실제 리플레이 관측
최초 실행 `krx100_pit_replay_20261028_r1`:

| 종목 | 전략 | 사전 가격 가정으로 완결된 거래 후보 | 최종 상태 |
|---|---|---:|---|
| 삼성전자 | 장초 모멘텀 30분 | 1건 | 6월 1일 불명확한 분봉 공백 중 가정 보유 → 미해결 |
| SK하이닉스 | 장초 모멘텀 30분 | 13건 | 7월 7일 서킷브레이커 중 가정 보유 → 미해결 |
| 삼성전자 | ORB 5·15·30분 | 각각 7·8·5건 | 가상 현금 상태 |
| SK하이닉스 | ORB 5·15·30분 | 각각 8·5·4건 | 가상 현금 상태 |

이 결과는 종목별 **독립 전략 계좌**의 상태이며 실제 증권사 체결 기록이 아니다. 기존 PR #103의 마지막 20거래일 가정 손익 -5.62%/-17.27%를 유효한 수익성 판단으로 승격시키지 않는다.

## 남은 확인 사항
1. KIS 분봉 시간 라벨(시작/종료) 공식 계약, 15:30/15:32 종료라벨 의미, 조정주가·기업행동 시점 증거.
2. KRX 공식 시장중단과 10분 단일가 재개 **정확한 체결 가능 시작 시각 및 실제 이벤트 전달 시각** 검증.
3. 미확인 원본 분봉 7건: 누락 시각·재수집 가능성·시장 자체 무체결인지 별도 증거 대조. 원본값 자동 보간 금지.
4. 미해결 포지션의 독립 체결 원장/호가/일별 계좌 대조 후에만 실제 추정 수익률·MDD·샤프 계산. 사전 등록된 새 테스트 기간으로 별도 재검증.
5. 실제 운영 90일 평가(기존 워크트리 `d6b531e`) 및 브로커 주문 경로에 연구 모델 자동 연결하지 않음.
