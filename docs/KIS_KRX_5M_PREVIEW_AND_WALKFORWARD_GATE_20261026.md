# FreeQuantLab: KRX 정규장 1분봉 → 5분봉 실증 및 워크포워드 준비 감사 (2026-10-26)

## 목적과 기존 연구엔진 연결

FreeQuantLab에는 이미 `quantlab.intraday_research`가 있으며, **시간대가 명시된 5분봉**, 정규장 76개 봉 × **최소 60개 완전 거래일**, 완료된 봉의 신호를 사용한 *다음 봉 시가* 진입, 검증 데이터에서만 후보 전략 선정 및 별도의 미사용 테스트 구간 평가를 요구한다.

이번 단계는 KIS가 실제로 수집된 **KRX J 역사 1분봉**만 엄격히 읽고, 정규장 **09:00~15:19 KST (380개 연속 라벨)**를 가정상 09:00, 09:05, ..., 15:15 시작 5분봉 **76개**로 변환하는 **연구용 후보 생성**이다.

- 15:20~15:29 KRX 종가 단일가 경매는 연속 체결로 가장하지 않음
- 15:30 별도 종가 경매 라벨과 16:00~20:00 애프터마켓은 5분봉에 혼합하지 않음
- NXT NX·통합 UN 분봉을 KRX J와 합산하거나 09:08 통합 이상을 보정하지 않음
- 누락된 1분 라벨은 임의 0주 채우기 금지; 원본/실시간·운영 DB는 불변
- `stck_cntg_hour`가 **분 시작인지 분 종료인지 KIS가 검증하지 않았기 때문에** 5분 시각은 시작을 가정한 *provisional label*이다. 이를 입증한 것처럼 기존 전략을 실행하지 않음.

## 2. 신규 코드

`quantlab.intraday_krx_5m_preview`

- 기존 SHA-256 원본 + 분봉·공식 일봉 검증 함수 `_read_one` 재사용.
- 6개 종목·일 원본이 모두 존재하고 각 380개 정규장 분 라벨이 빠짐없어야 출력. 개별 1분 OHLC 모순·음수 거래량·다른 날짜 자료 차단.
- 시가: 해당 5개 분봉 첫 시가; 고가·저가: 최대/최소; 종가: 마지막 분봉 종가; 거래량: 5개 분봉 합.
- **1분 380개 → 5분 76개**, 부피 보존 검사. 별도 공식 일봉과 연속봉 수량의 차이는 정보 필드이며 다른 거래구간으로 임의 귀속하지 않음.
- 원본·재조회본 쌍이 있으면 **1분봉 해시 변경과 5분봉 OHLCV 변경을 분리**해 기록.
- 결과는 `*_candidate_5m_UNVERIFIED.json`으로만 기록하고 ***사용 가능한 CSV가 아님***. 불변 JSON/SHA 출력을 만들며 **절대 백테스트 평가 함수를 호출하지 않음**.
- 출력 `readiness_by_symbol`에는 기존 전략엔진의 최소 60일, 5분봉 거래일 수, 5분봉 시간 의미 미확정, 전략 워크포워드 평가 차단 상태를 명시.
- **네트워크 API 수집기**는 기존의 보수적 제한(한 배치 최대 3종목 × 5과거 평일)을 그대로 유지하지만, **이미 저장된 소스의 오프라인 집계기**는 3종목 × **최대 120개 과거 평일**을 받아 60개 이상 거래일을 구성할 수 있다. 거래일 입력은 중복/역순/미래/주말/경로탈출을 차단한다. 거래소 휴장일은 평일 달력만으로 입증되지 않으므로 미리 확보한 정상 원본이 없는 날은 거부한다.

## 3. 실제 오프라인 실행

이미 아래 명령으로 WSL에서 성공했고, 재실행 시 원본을 덮어쓰지 않도록 결과가 불변 저장됐다.

```bash
cd /home/hong/apps/FreeQuantLab-intraday-20261026
PY=/home/hong/apps/FreeQuantLab/.venv/bin/python
R=/home/hong/apps/FreeQuantLab/state/intraday_research

"$PY" -m quantlab.intraday_krx_5m_preview \
  --source-root "$R/venues_cohort_20261026_run1" \
  --baseline-root "$R/venues" \
  --out-dir "$R/krx_5m_preview_20261026_run1"
```

아래 파일들을 생성했다.

- `krx_5m_preview_20261026_run1/005930_candidate_5m_UNVERIFIED.json` (228개)
- `krx_5m_preview_20261026_run1/000660_candidate_5m_UNVERIFIED.json` (228개)
- `krx_5m_preview_20261026_run1/candidate_5m_summary.json` (6개 종목·일의 원본/재조회/워크포워드 준비 상황과 SHA)

**모두 연구 출력이며 `usable_for_backtesting=false`**. 서명된 소스가 있더라도 **분봉의 실제 시간 의미/체결 계약/비용 모델은 아직 승인되지 않았다.**
