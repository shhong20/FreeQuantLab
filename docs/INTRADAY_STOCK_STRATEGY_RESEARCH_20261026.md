# FreeQuantLab: 주식 5분봉 단타 전략 비교 (격리 연구 전용, 2026-10-26)

## 범위와 금지선

- **별도 모듈** `python -m quantlab.intraday_research`. 기존 `quantlab.engine`, 주식 일봉 원장, Qlib frozen 모델, BTC/ETH 90일 평가, Shadow/가상주문, timer, API, 증권사 주문 코드를 변경하지 않는다.
- 입력은 **과거의 검증된 정규장 5분봉 CSV**이며, 자동 내려받기나 브로커 주문은 없다.
- 기존 8,022개 일봉은 이 모듈의 분봉 데이터가 아니다. 이 PR은 전략 검증 **엔진과 합성 데이터 테스트**를 추가한 것이지 과거 실시장 수익률을 산출한 것이 아니다.
- 모든 보고서는 `ISOLATED_INTRADAY_RESEARCH_ONLY_NOT_PAPER_ELIGIBLE`로 표시하며, Paper / 90일 자동 승격은 없다.

## CSV 데이터 계약

각 행은 5분 구간의 **시작 시점**이다. ISO 8601 timezone offset을 반드시 포함한다.

```csv
timestamp,open,high,low,close,volume
2026-10-20T09:00:00+09:00,100,101,99,100.5,12000
2026-10-20T09:05:00+09:00,100.5,101.5,100.1,101,18000
```

위의 두 줄은 스키마 예시로 **실행 가능한 데이터셋이 아니다**. 입력은 최소 60거래일 × 정규장 78개 봉이 필요하며, 모든 지정 거래일에 정규장 **연속 78개**가 있어야 한다. 한국은 09:00–15:30 KST, 미국은 09:30–16:00 America/New_York (서머타임 자동). 단축장, 거래정지·결측, 분봉 중복, 모호한 시간대, 아직 완성되지 않은 세션은 거부한다. 전체 휴장일은 자동 생성하거나 채우지 않는다. 이 1차 버전은 공식 거래소 달력·액면분할·배당·분배금 검증 자체를 수행하지 않으므로 **투자 성과 확인 근거로 사용할 수 없다**.

서로 다른 종목의 5분봉을 한 CSV에 섞으면 안 된다. 데이터 공급원, 종목, 수정 여부, 거래정지, 호가단위, 과거 시점 기준 기업행동 검증을 별도 원장에 보존하는 후속 확장이 필요하다.

## 전략 및 시간 계약

| 후보 | 신호 | 실행 가정 |
|---|---|---|
| ORB 5·15·30분 | 첫 N개 완료봉 고점 위로 이후 5분봉 종가 돌파; 첫 N개 구간 거래량이 **이전 20거래일 중 최대 20개의 동시간대 거래량 중앙값 대비 1.5배**이고 이전 데이터 최소 10거래일 | 신호 다음 봉 **시가 매수**, 해당일 마지막 5분봉 **시가 매도** |
| 갭 하락 반전 0.75%, 1.5% | 전 거래일 마지막 봉 **종가** 대비 당일 첫 봉 시가가 하락, 첫 봉 양봉일 때만 Long. **운영자의 기업행동 사전 검증 선언 필요** | 첫 봉 완료 후 다음 봉 시가 진입; 마감 전 매도. 공매도 없음 |
| 장 초반 모멘텀 30분 | 첫 6개 완료봉의 마지막 종가가 당일 첫 시가 대비 0.2% 이상 | 다음 봉 시가 진입; 마감 전 매도 |

- 모든 신호는 완료된 봉만 보며, **신호를 만든 봉의 종가에 동시 체결했다고 가정하지 않는다**.
- 첫 N개 구간 상대 거래량 기준에 당일 거래량을 섞지 않는다. 전 거래일 종가도 다음 거래일에만 사용한다.
- 종가 청산으로 미래 체결가격을 사용하지 않도록 **마지막 5분봉의 시가**에 청산한다. 그러나 이 가격 역시 주문장/거래량/미체결 시뮬레이션 없이 가정한 가격이므로 실거래 체결 보장은 없다.
- 체결비용: 매수 `(수수료+슬리피지)`, 매도 `(수수료+슬리피지+매도세)`를 거래 건별 차감. 한국 일반주식은 **가정치** 20bps 매도세, 한국 ETF와 미국 주식은 기본 0bps(그 외 규제수수료, 환전비용 등 미포함). 매도세·비용을 반드시 실제 계좌 및 거래시점에 맞게 검증하라.
- **환헤지, 환전, 배당, 종목당 투자한도, 호가/주문잔량, 갭 중 뉴스, 거래제한, 차입·공매도 등은 미모델링**.

## 실행 예시 (읽기 전용)

```bash
python -m quantlab.intraday_research \
    --csv /absolute/path/to/verified_krx_stock_5m.csv \
    --market KRX_STOCK \
    --fee-bps 3 --slippage-bps 5 \
    --sell-tax-bps 20 \
    --out /absolute/path/to/reports/intraday_krx_stock.json

# 전 거래일 종가와 corporate action을 독립 검증한 경우만:
python -m quantlab.intraday_research \
    --csv /absolute/path/to/reviewed_krx_5m.csv \
    --market KRX_STOCK --corporate-actions-reviewed \
    --out /absolute/path/to/reports/intraday_reviewed_gap.json
```

첫 실행은 **갭 전략을 비활성화**하고 ORB·모멘텀 연구만 가능하다. 둘째는 사용자 선언 플래그이지 공식 검증 인증이 아니다.

- 원본 CSV `SHA-256` 및 기간, 비용, 후보기법, 후보별 검증 성적, 검증 기간에 고정된 선택, 미사용 테스트 기간 성적을 JSON에 기록한다.
- 데이터 날짜 순으로 60% 준비기간 / 20% **검증기간** / 20% **한 번만 관찰할 테스트기간**. 각 전략군의 파라미터는 검증기간 복리 순수익률을 기준으로만 선택하며, 검증기간 최소 3거래 및 테스트기간 최소 10거래가 안 되면 부족 상태를 표시한다. 준비기간은 거래량 기준 warm-up 외 파라미터 학습이 없다.
- 이 분할이 시간적 미래누설의 **모든 원인**을 해결한 것은 아니다. 공급원 시점, 수정주가, 상장폐지·생존편향, 종목 선택, 정책 변경, 다중검정 등은 별도 통제해야 한다.
- 임의로 후보 수를 늘려 과거 최상위만 고르면 과최적화되므로, 후속 실데이터 검증에서 사전등록, 여러 기간의 워크포워드, 종목군 분리, 거래비용 2배 스트레스, 시장 국면별 결과를 추가한다.

## 실제 시장 검증 전에 필요한 일

1. 한국/미국의 **원본 5분봉 보유기간과 제공 라이선스** 확인, 기업행동/거래정지/단축장 원장과 시간대 계약 수립. 기존 일봉 테이블을 분봉으로 확장하는 것은 금지.
2. 적어도 1년 이상 분봉의 시점 누설 없는 데이터를 분리 저장하고 원본 응답 SHA 및 거래시간·중복·수정·결측 감사를 진행한다.
3. 전략별 동일 거래비용·슬리피지·체결 가능량·개별 종목과 ETF 비교, 장기간 진짜 **미사용 데이터**와 여러 시장에서 검증한다.
4. 충분한 표본과 비용 반영 결과가 나온 후에도 별도 승인 없이 운영 중 가상·실거래 전략으로 자동 연결하지 않는다.
