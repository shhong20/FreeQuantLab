# KRX 표시 호가 기반 동적 비용 민감도: 실제 자료·백테스트 가정 비교 (2026-10-28)

## 목적
연구 전략에 적용된 **편도 고정 5bp 슬리피지 가정**과, 한국투자증권에서 실제 관측한 삼성전자·SK하이닉스 10호가 화면의 가격·잔량을 비교한다. 과거 5분봉 시가 기준 비용과 **현시점 호가 중간가격(midpoint) 비용의 기준점이 다르므로**, 둘의 차이를 실제 과거 슬리피지 오차나 실전 수익률이라고 부르지 않는다.

분봉·시장 체결틱·호가가 서로 다른 시각에 기록되는 점, 호가 대기열·취소·주문 왕복지연·미공개 잔량이 측정되지 않는 점을 유지한다. KIS 시세 응답은 **개인 주문 체결증빙이 아니다**.

## 실제 KIS 응답 12개 재검증

- 입력: `/home/hong/apps/FreeQuantLab/state/intraday_research/krx_live_l2_20261028_r2`
- KRX J, 삼성전자 `005930`, SK하이닉스 `000660`, 2026-10-28 13:23 KST 무렵 각각 6회씩 확보한 총 12개 10호가 스냅샷.
- 개별 `raw-*.json` 원문 SHA-256 확인 → KIS 실제 원문을 다시 해석 → `quote-*.json` 정규화 데이터와 완전 동일 여부 검증.
- R1에서는 응답 원문 자체가 별도 저장되지 않았으므로 그 12개 표본은 이번 **원본 독립 검증 자료에서 제외**. R1/R2를 합쳐 24개 신뢰 가능한 원본이라고 주장하지 않는다.

## 원화 예산별 주문 가능성

| 주문 예산 | 삼성전자 매수 | SK하이닉스 매수 |
|---|---|---|
| 100만 원 | 1주 이상 가능, 표시 호가 기준 10.363bp | **0주**: 단일 주식 가격이 예산 초과 |
| 1,000만 원 | 1주 이상 가능, 10.363bp | 1주 이상 가능, 3.389bp |
| 1억 원 | 1주 이상 가능, 10.363bp | 1주 이상 가능, 3.389bp |

이는 **단일 주가와 당일 호가 잔량**으로 계산한 가능 여부만 뜻하며, 주문 접수/전량 체결 가능성이 보증된 것은 아니다. 10호가 잔량이 모자라거나 최소 1주를 살 수 없는 예산이면 VWAP/비용을 **null**로 기록하고 0비용·정상 체결로 간주하지 않는다. 세금·수수료·미체결 비용·실제 주문 지연은 미포함.
