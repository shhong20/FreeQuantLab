# KRX 100거래일 원본 전수조사 및 시간순 RVOL 누설 수정 (2026-10-28)

## 범위
- KRX J 삼성전자(005930), SK하이닉스(000660), 2026-05-28~10-23 실제 100거래일, 200개 종목·거래일 원본.
- 입력: SHA 검증 `krx100_backfill_plan_20261028_r2`, KIS 원본 `venues_cohort_20261026_run1`, 위험 분리 자료 `krx100_halt_5m_20261028_r2`.
- 원본·운영 평가·실거래·가상매매 코드를 수정하거나 데이터를 보간하지 않음.

## 1. 실제 원본 200건 전수 확인
`quantlab.intraday_krx_source_triage`가 모든 원본의 KIS 수집 페이지 SHA, 분봉 관측, 일봉 대조, 종목·거래일 일치를 다시 검사하고 별도 불변 JSON/SHA 파일로 남긴다.

| 검사 | 결과 |
|---|---:|
| 해시·원본 일관성 확인 | 200건 |
| 서킷브레이커 등 별도 위험 사례 | 기존 16건 유지 |
| CB 밖 원인 미확인 분봉 누락 | **7개 종목·거래일, 실제 결측 13분 라벨** |
| 15:32 종가 라벨 | **5건** |
| 마지막 관측 분봉 가격과 해당 KIS 일봉 종가 차이 | **0건/200건** |

미확인 분봉 13라벨:
- 삼성전자 06-01 15:00(1분), 07-31 09:00·09:01(2분).
- SK하이닉스 06-25 09:00·09:01(2분), 07-03 14:18(1분), 07-08 10:14·14:30(2분), 07-15 09:00·09:01(2분), 07-31 09:00·09:01·09:03(3분).

마지막 체결시간 라벨 15:32: 삼성전자 06-29·08-13·10-08, SK하이닉스 06-24·07-02. 5건 모두 KIS 공식 일봉 종가 **가격**과는 같지만, **15:32가 실제 15:30 단일가 체결을 나타낸다는 공인 시간 규약은 확보하지 못함**. 기존 5건의 보류는 유지한다.

KIS 공식 API 예제에서는 `FID_FAKE_TICK_INCU_YN`이 허봉 포함 여부로 표기되고, 실제 이전 수집기는 값을 `""`로 전달했다. 따라서 일부 분봉 라벨 미관측은 단순 네트워크 누락인지, 거래가 없는 시각인지, 호가·단일가/서킷브레이커 관련 시장 현상인지 공식적으로 구분되지 않는다. **미관측 분봉을 0 거래량으로 채우거나 양쪽 가격으로 보간하지 않음.**

공식 API 예제: https://github.com/koreainvestment/open-trading-api/blob/main/MCP/Kis%20Trading%20MCP/configs/domestic_stock.json

## 2. 과거 ORB 상대거래량(RVOL) 편향 수정
이전 `intraday_krx_pit_replay._replay_one`은 당일 **오후에** 거래중단 또는 소스 결측이 발생하면 이미 오전 09:00에 완전히 관측한 N분 거래량도 다음 날 RVOL 이력에서 삭제했다. 이 규칙은 나중 발생한 사건으로 과거 관측을 선택해 버리는 **미래정보 기반 데이터 선별**이었다.

수정 후:
- ORB 5·15·30분 기준 거래량을 **각 N분의 관측 완전성**으로 별도 판단.
- 오후 누락/중단 여부와 무관하게 이미 확인된 개장 분봉은 다음 날 과거 거래량 기준에 사용.
- 과거 분봉 자체가 누락된 N분이라면 해당 N분 기준값만 생성하지 않고 다음 날 거래량 기준에서 제외.
- 그날 **진입/보유 위험 처리와는 독립적**으로 누적. 새로 발견되는 포지션 미해결 위험은 원금 회수나 청산 체결을 상상하지 않고 보류.

실제 100일 재실행 결과(현재도 **시뮬레이션이며 미검증 체결**):
- 삼성전자 ORB 5분: 가정 청산 완료 7→2건, 07-29 12:00 소스 누락 이전 가상 진입 → `FROZEN_UNRECONCILED`.
- 삼성전자 ORB 15분: 8→7건, 현금 시뮬레이션 상태.
- SK하이닉스 ORB 5분: 8→7건, 현금 시뮬레이션 상태.
- 그 외 변종은 기존 시나리오 상태 및 가정 청산 횟수 유지.
- 기존 모멘텀 보유 위험: 삼성전자 06-01 미확인 공백, SK하이닉스 07-07 CB 중단 유지.

**위 변화는 실제 수익 성과가 아니며**, CB·누락의 시점 지식만으로 실행 가능한 체결을 증명하지 않는다. 1분 시작/끝 라벨, 브로커 체결가·미체결, 정확한 공식 KRX 복구 시각은 여전히 불확실.
