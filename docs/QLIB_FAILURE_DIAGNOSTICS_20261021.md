**평가 성격: 탐색적 사후 원인 진단. 기존 실험·전략을 소급 수정하거나 새 투자 신호를 선택하지 않음.**
기존 `docs/QLIB_CAUSAL_HISTORICAL_20261021.md`의 BTC/ETH 각 3,000일 실거래소 공개 일봉, 초기 600일 학습 후 각각 20개 × 약 120일의 비중첩 2,398일 OOS, 실제 `qlib.contrib.model.gbdt.LGBModel` 재학습 경로를 그대로 재사용하였다.

## 기술적 재현 계약

- 코드: `quantlab/qlib_failure_diagnostics.py`와 `quantlab/qlib_historical_stress.py`. 추가 결과: `failure_diagnostics`. 모델 설정·매매 임계값·전략 선택 및 기존 수익률 계산은 변경하지 않았다.
- 예측일 t는 **종료된 UTC 일봉 종가까지의 정보**로 결정. 사후 정답은 다음 시가 t+1에서 그다음 시가 t+2까지의 수익률이 **0 초과**인지로 표시. 이 라벨은 평가 함수에서만 사용하며 학습 데이터·임계값·리스크 조절로 되돌리지 않는다.
- 폴드별 ROC-AUC, 방향 정확도(0.50/0.55), 양수 수익일 비율, Brier, 상수 예측 p=0.5의 Brier, log-loss, 미리 고정한 확률 구간의 관측 상승 비율을 기록. 표본 1개 또는 상승/하락 한쪽만 있는 경우 ROC-AUC는 null.
- **미래 정보가 아닌** 종료된 일봉까지의 60일 추세/20일 변동성 상대 비교로 상승·하락·횡보 및 고/저 변동 국면을 분류. 15bp 가정 수익률의 해당 일별 **매수·보유 대비 로그 초과수익**만 국면별로 합산. 단순한 비연속 국면 수익률을 단독 복리 운용 성적으로 주장하지 않는다.
- 비용 0/15/30/60bp는 편도 거래대금 기준의 **모델 비용 가정**. 비용 0 대비 15bp, 15 대비 60bp에서 감소한 전략 총 로그수익으로 **회전율/비용 기여**를 분리한다. 이 비용은 실제 체결 호가·시장충격 또는 펀딩을 포함하지 않는다.
- 입력 CSV 해시 검사 및 기존 보존 800일 OHLCV 교차검증은 그대로 실행. 기존 90일 원장·Exaone/Qlib 실시간 실험 타이머·실거래 주문 기능에는 접근하지 않음.
- 현재 연구 전체는 이전에 여러 차례 조사한 과거 데이터를 반복 분석하므로, 모델 선택 후 새롭게 확보한 독립적인 미공개 홀드아웃으로 해석할 수 없다.

## 향후 우선순위 — 코드와 전략 분리

1. 현재 시점에 알고 있는 변수/라벨 정의가 예측할 목표 수익과 일치하는지 추가 감사. 특히 `next_open → following_open` 일간 방향예측과 **저빈도 포지션 유지**는 최적화 목표가 다르다.
2. 새로운 학습 목적과 매매 규칙 설계 시에는 먼저 전략 후보군과 검증 기간을 잠그고, 평가 데이터를 반복 열람하며 매개변수를 조정하지 않는다.
3. 모델 확률 교정(예: Platt/등장률 베이스라인)은 OOS 레이블이 아닌 **그 폴드의 학습/검증 구간에서만** 학습해야 한다. 이 보고서의 확률 구간표는 사후 평가이지 모델 교정이 아니다.
4. BTC·ETH 외 자산·시장 스트레스와 시간대/체결 프록시 위험을 평가한 뒤 실시간 선행 모의운용을 제한적으로 재개한다.
5. Exaone은 2026년 모델로 2018~2025년 의사결정의 정확한 역사적 재현을 할 수 없으므로, 정보 유출 가능성과 실제 고정 프롬프트/모델 증거가 있는 새 날짜부터 선행 평가한다.
